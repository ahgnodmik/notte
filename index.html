notte 개인정보 처리방침

최종 업데이트: 2025년 5월 17일

1. 개인정보 수집 여부

본 앱은 로그인 기능 없이 사용되며, 이메일, 연락처, 위치정보 등 어떠한 개인정보도 수집하지 않습니다. 사용자의 노트, 일정 등의 모든 데이터는 오직 기기 내에만 저장되며 외부 서버로 전송되지 않습니다.

2. 데이터 저장 및 삭제

모든 데이터는 기기 로컬 저장소에만 존재하며, 앱 삭제 시 해당 데이터는 복구 불가능하게 삭제됩니다. 본 앱은 서버 기반 백업을 제공하지 않으며, 사용자가 데이터를 보존하려면 앱 내 Export 기능을 직접 사용해야 합니다. Export 기능은 앱 내부에서만 제공되며, 개발자는 파일을 수집하거나 전달하지 않습니다.

3. Import 기능 및 파일 형식

향후 제공될 Import 기능은 JSON, CSV 등 효율적인 파일 형식을 통해 구현되며, 모든 동작은 로컬 기기 내에서만 처리됩니다. 외부와의 네트워크 연동이나 데이터 전송은 이루어지지 않습니다.

4. 외부 연동 및 추적 없음

notte는 광고, 사용자 분석, 추적 기능을 포함하지 않으며, 외부 API 또는 서버와 어떠한 정보도 공유하지 않습니다. [xchange 페이지](https://ahgnodmik.github.io/xchange/)와 같은 외부 데이터는 브라우저 기반으로 표시되며 사용자 정보는 수집되지 않습니다.

notte Privacy Policy

Last Updated: May 17, 2025

1. No Personal Data Collection

This app does not require login and does not collect any personal information such as email, contact number, or location data. All content (notes, schedules, etc.) is stored only on the user's device and is never transmitted externally.

2. Data Storage and Deletion

All data is stored locally on the device. Deleting the app will permanently erase all data. The app does not support server-based backup. Users must manually export their data within the app. The export feature is only available in-app, and the developer does not collect or handle any files.

3. Import Feature and File Format

An import feature will be supported using the most efficient file formats (e.g., JSON, CSV). All actions will be performed locally with no external network communication or data transfer.

4. No External Tracking or Data Sharing

notte includes no ads, analytics, or tracking systems. No personal data is ever shared with third parties. Features such as the [xchange page](https://ahgnodmik.github.io/xchange/) display information locally without collecting any user data.

5. Contact Information

Developer email: samdongpm@gmail.com

notte is built to prioritize user privacy, and all data remains exclusively on the user's device.
