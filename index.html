notte 개인정보 처리방침

최종 업데이트: 2026년 11월 5일

1. 개인정보 수집 여부

본 앱은 로그인 기능 없이 사용되며, 이메일, 연락처, 위치정보를 직접 수집하지 않습니다. 사용자의 노트, 일정 등의 콘텐츠 데이터는 오직 기기 내에만 저장되며 개발자 서버로 전송되지 않습니다. 다만 앱 품질 개선 및 광고 제공을 위해 Google Firebase Analytics 및 Google Mobile Ads SDK가 앱 사용 정보, 기기 정보, 기기 또는 기타 ID(예: 광고 ID, 앱 인스턴스 ID)를 수집할 수 있습니다.

2. 데이터 저장 및 삭제

모든 데이터는 기기 로컬 저장소에만 존재하며, 앱 삭제 시 해당 데이터는 복구 불가능하게 삭제됩니다. 본 앱은 서버 기반 백업을 제공하지 않으며, 사용자가 데이터를 보존하려면 앱 내 '백업 · 내보내기' 기능을 직접 사용해야 합니다. 내보낸 파일은 사용자가 선택한 기기 내 위치에 저장되거나 사용자가 선택한 앱으로 공유되며, 개발자는 파일을 수집하거나 전달받지 않습니다.

3. 백업 가져오기 및 파일 형식

노트는 JSON 백업 파일과 Excel, CSV 파일로 내보낼 수 있으며, JSON 백업 파일을 가져와 노트를 복원할 수 있습니다. 가져오기는 사용자가 직접 선택한 파일만 읽으며 모든 처리는 기기 내에서 이루어지고, 외부 서버로 전송되지 않습니다.

4. 광고, 분석 및 제3자 SDK

notte는 Google Firebase Analytics를 사용하여 앱 사용 통계를 분석하고, Google Mobile Ads SDK를 사용하여 광고를 표시할 수 있습니다. 이 과정에서 Google이 기기 또는 기타 ID, 앱 상호작용, 진단 정보 등 데이터 보안 양식에 고지된 정보를 처리할 수 있습니다. 사용자가 작성한 노트 콘텐츠는 이 SDK들에 전달되지 않습니다.

5. 문의 및 연락처

개발자 이메일: samdongpm@gmail.com

notte는 사용자 프라이버시 보호를 중요하게 여기며, 사용자가 작성한 노트 및 일정 콘텐츠는 오직 사용자의 기기 내에서만 처리됩니다.

notte Privacy Policy

Last Updated: November 5, 2026

1. Personal Data Collection

This app does not require login and does not directly collect email, contact number, or location data. User-created content such as notes and schedules is stored only on the user's device and is not transmitted to the developer's server. However, Google Firebase Analytics and Google Mobile Ads SDK may collect app usage information, device information, and device or other IDs such as advertising ID and app instance ID for analytics, app quality, and advertising.

2. Data Storage and Deletion

All data is stored locally on the device. Deleting the app will permanently erase all data. The app does not support server-based backup. Users must back up their data themselves using the in-app 'Backup & Export' feature. Exported files are saved to a location on the device chosen by the user or shared to an app chosen by the user, and the developer does not collect or receive any files.

3. Backup Import and File Formats

Notes can be exported as a JSON backup file and as Excel or CSV files, and notes can be restored by importing a JSON backup file. Import reads only the file selected by the user, and all processing happens on the device without transmission to external servers.

4. Ads, Analytics, and Third-Party SDKs

notte uses Google Firebase Analytics to understand app usage and may use Google Mobile Ads SDK to display ads. During this process, Google may process data disclosed in the Google Play Data safety form, including device or other IDs, app interactions, and diagnostics. The content of notes written by users is not passed to these SDKs.

5. Contact Information

Developer email: samdongpm@gmail.com

notte is built to prioritize user privacy, and user-created note and schedule content remains on the user's device.
